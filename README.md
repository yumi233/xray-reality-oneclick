# Xray Reality Oneclick

一键部署 Xray VLESS + REALITY 节点。

## Install

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yumi233/xray-reality-oneclick/main/install.sh)
```

功能：
- 自动安装 Xray-core
- 自动生成 UUID
- 自动生成 REALITY 密钥
- 自动写入配置
- systemd 自启动
- 输出 VLESS 链接

## Requirements

- Ubuntu 22.04 / 24.04
- root 权限
